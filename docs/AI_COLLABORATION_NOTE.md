## 2. Specific Work Delegated to AI

- **Drafting Code Templates**: Fast boilerplate generation for FastAPI route declarations, Pydantic v2 schemas, and CSS variables.
- **Synthesizing Adversarial Test Cases**: Generating realistic prompt injection vectors (e.g. system prompt overrides, instruction bypass tags, base64 instructions) to stress-test the input parser.
- **Documenting API Payloads**: Structuring Greenhouse Harvest API JSON models and standard webhook fields.

---

## 3. How AI-Generated Results Were Rigorously Verified

Every output generated by AI was subjected to strict deterministic validation before entering the codebase:
1. **Automated Unit Testing (`pytest`)**: 6 core unit test suites validating PII redaction, prompt injection quarantine, parser error handling, and ATS exporter schema compliance.
2. **Automated 10-Case Evaluation Suite (`run_eval.py`)**: End-to-end execution of golden hires, transitioners, keyword stuffers, and career-gap resumes with strict score range and recommendation checks.
3. **Execution Profiling**: Benchmarking latency to guarantee sub-20ms execution times without external API hangs.
4. **Manual UI Verification**: Interactive verification of file uploads, score circular gauges, evidence quote highlighting, and human approval sign-off flows.

---

## 4. Important Results Rejected or Manually Corrected

1. **Rejected: Pure LLM Free-Form Text Scoring**:
   - *AI Initial Suggestion*: Let an LLM generate arbitrary text reviews and assign scores via zero-shot prompting.
   - *Reason Rejected*: Zero-shot LLMs produce score drift (scoring the same resume 82 on one call and 91 on another), suffer from hallucination, and cannot guarantee exact textual quote citations.
   - *Correction*: Engineered a deterministic grounded scoring engine where 100% of score conclusions are mathematically weighted and linked to exact substrings from the applicant's resume.
2. **Corrected: Max Single-Stint Tenure Calculation**:
   - *AI Initial Code*: Used `max(date_diffs)` to determine experience years.
   - *Defect Discovered in Day 4*: Sarah Jenkins (Principal Architect with an 18-month family sabbatical) was penalized as having only 5 years of tenure.
   - *Correction*: Rewrote the interval math to compute non-overlapping cumulative intervals across all employment periods, restoring full credit for multi-stint senior candidates.
3. **Rejected: Heavy Frontend Framework Dependencies**:
   - *AI Initial Suggestion*: Scaffolding a Vite/React application with Tailwind and npm packages.
   - *Reason Rejected*: Evaluators assessing a 5-day sprint often encounter Node version conflicts, missing peer dependencies, or build tool lockups.
   - *Correction*: Implemented a clean, zero-build Vanilla CSS/HTML/JS architecture that launches instantly with pure Python.

---

## 5. Core Architectural Decisions Personally Owned

- **Human-in-the-Loop Approval Gate**: Deciding that the AI OS should never autonomously send rejections or advance candidates into ATS without explicit human recruiter sign-off.
- **Security Quarantine Architecture**: Establishing the boundary that raw user document text must pass through `AdversarialGuard` before any semantic parsing or evaluation takes place.
- **Rubric Weighting Calibration**: Setting the four weighted pillars: 35% Technical Competency, 30% Tenure & Seniority, 20% Quantified Impact, 15% Preferred Tooling.
- **Portability & Zero-Cost Evaluation Guarantee**: Ensuring the entire system runs out-of-the-box in offline synthetic mock mode without requiring evaluators to configure paid external API keys.
